# LUMEN DRIFT

Pilot the salvage skiff Kestrel through a collapsing nebula. Gather each wave's shard quota, survive ten waves, and claim the Heart Shard to reignite the Shattered Star. An original top-down arena arcade game in vanilla JavaScript: four enemy kinds, combo scoring, dash with invulnerability, shield and overcharge pickups, synthesized WebAudio, and a full loop from title screen to victory or defeat.

## Controls

- WASD or arrow keys: thrust with drift
- Mouse: aim; hold left button to fire
- Space: dash with brief invulnerability
- P: pause; M: mute
- Enter or click: start; R or click after an ending: restart

## Run it

```sh
node serve.ts
```

Then open `http://localhost:8080`. Needs Node 22; the game is static files under `game/` with no network request.
