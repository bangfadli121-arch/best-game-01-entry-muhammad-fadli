# RUST RUMBLE

Take your chunky little bot into a sunny floating junkyard ring. Bump and dash through the scrap draft, face the SCRAP KING, and stay sharp as the ring shrinks from round 2 onward. Win two rounds to become champion of the yard.

Shove them off the edge to win the round.

## Controls

- WASD or arrow keys: move
- Space: dash
- P: pause or resume
- M: mute or unmute
- Enter or click: start, or restart after a match
- R: restart after a match

## Run it

Run `node serve.ts`, then open http://localhost:8080.
