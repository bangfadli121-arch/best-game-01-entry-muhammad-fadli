# LUMEN DRIFT

Pilot the salvage skiff Kestrel through a collapsing nebula. Gather each wave’s shard quota, survive ten waves, and claim the Heart Shard to reignite the Shattered Star.

## Controls

- WASD or arrow keys: thrust with drift
- Mouse: aim; hold left button to fire
- Space: dash with brief invulnerability
- P: pause; M: mute
- Enter or click: start; R or click after an ending: restart

## Run locally

Use Node 22 and run `node serve.ts` from this directory, then open `http://localhost:8080`.
